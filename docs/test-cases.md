```markdown
Тест-кейсы

TC-01: Проверка валидации пустой формы обратной связи
Предусловие: Открыта страница `authorization.html`, открыто модальное окно поддержки.
Шаги:
    1. Оставить поля «Почта» и «Сообщение» пустыми.
    2. Нажать кнопку «Отправить».
Ожидаемый результат: Форма не отправляется. Появляется красная плашка «Проверьте введённые данные», поля подсвечиваются красным.

TC-02: Фильтрация каталога по типу "Аудитории"
Предусловие: Открыта страница `catalog.html`.
Шаги:
    1. В левой панели в фильтре «Тип ресурса» выбрать «Аудитории».
    2. Нажать «Применить фильтры».
Ожидаемый результат: На экране остаются только карточки с бейджем «АУДИТОРИЯ».

TC-03: Успешное бронирование аудитории
Предусловие: Открыта страница `calendar.html`.
Шаги:
    1. Кликнуть по пустой ячейке в сетке календаря (например, Вт, 17, 12:00).
    2. В открывшемся модальном окне нажать «Подтвердить бронирование».
Ожидаемый результат: Появляется синяя плашка «Бронирование успешно создано». Ячейка на календаре становится серой («Занято»). Данные сохраняются в LocalStorage.

TC-04: Отмена брони
Предусловие: Открыта страница `bookings.html`, есть минимум одна активная бронь.
Шаги:
    1. Нажать «Отменить бронь» на карточке.
Ожидаемый результат: Страница перезагружается, карточка исчезает из списка. Данные удаляются из LocalStorage.
```
