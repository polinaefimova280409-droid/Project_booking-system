```markdown
Чек-лист тестирования проекта «ИТ-МОСКВА»

1. Авторизация и формы
- Форма входа пропускает на главную страницу.
- Модальное окно «Обратная связь» открывается и закрывается.
- Валидация: кнопка «Отправить» не работает, если поля пустые.
- Валидация: появляется красная рамка и текст ошибки при неверном формате почты (без @).
- При успешной отправке появляется синяя плашка об успехе.

2. Главная страница и Поиск
- Ввод названия и выбор типа перенаправляют в Каталог.
- Параметры поиска передаются в URL (например, `/catalog.html?type=Ноутбук`).

3. Каталог ресурсов
- Фильтрация по типу (Аудитории/Оборудование) работает мгновенно.
- вод вместимости скрывает оборудование (так как у него нет мест).
- Кнопка «Сбросить фильтры» очищает все поля.

4. Календарь и Бронирование
- Клик по свободному слоту в календаре выделяет его синим.
- Модальное окно открывается с правильной датой и временем.
- Данные сохраняются в `localStorage` после подтверждения.

5. Мои брони
- Созданная бронь отображается в разделе «Активные».
- Вкладки «История» и «Отмененные» переключают контент.
- Кнопка «Отменить бронь» удаляет карточку и очищает `localStorage`.

6. Адаптивность (Мобильные устройства)
- Шапка сайта остается в строчку.
- Карточки в каталоге выстраиваются в один столбец.
- Календарь можно прокручивать свайпом по горизонтали.
```
