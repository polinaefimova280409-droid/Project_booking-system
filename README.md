# Система бронирования аудиторий и оборудований
Ефимова Полина и Батаев Глеб



ИТ-МОСКВА — Единый сервис бронирования
Веб-приложение для студентов и сотрудников колледжа, позволяющее искать, фильтровать и бронировать учебные аудитории и оборудование. Проект выполнен на чистом стеке Frontend-технологий.

Технологический стек
- HTML5 - семантическая верстка страниц.
- CSS3 - адаптивная верстка (Flexbox, Grid, Media Queries), кастомные модальные окна.
- JavaScript - динамическая фильтрация, интерактивный календарь.
- LocalStorage - локальное сохранение данных о бронированиях в браузере пользователя без использования сервера.


Как запускать
Проект не требует сложной сборки или установки сторонних зависимостей (npm install), так как написан на чистом HTML/CSS/JS.

Требования:
- Современный браузер (Chrome, Firefox, Edge, Safari).
- (Опционально) Node.js - для запуска локального сервера, чтобы избежать возможных ограничений браузера при работе с локальными файлами.
  Проверить наличие Node.js можно командой в терминале:
    ```bash
    node -v
    ```

Способ 1. Запуск через VS Code
1. Откройте папку с проектом в Visual Studio Code.
2. Установите расширение Live Server.
3. Нажмите правой кнопкой мыши на файл authorization.html (или main.html) и выберите "Open with Live Server".

Способ 2. Прямой запуск
Вы можете просто открыть файл authorization.html двойным кликом. Благодаря использованию localStorage, логика сохранения броней будет работать корректно даже без локального сервера.

Инструкции:

Авторизация
1. Перейдите на страницу authorization.html.
2. Нажмите кнопку «Войти через IT-Team» (для теста откроется главная страница).
3. Если возникли проблемы со входом, нажмите на ссылку «Не получается войти?». Откроется модальное окно поддержки, где можно отправить сообщение (сработает валидация полей).

Поиск и фильтрация ресурсов
1. Находясь на Главной, введите название ресурса (например, «Ноутбук») и выберите дату.
2. Нажмите «Найти ресурс» - вас перенаправит в Каталог с уже примененными фильтрами.
3. В Каталоге можно использовать левую панель фильтров: выбрать тип (Аудитория/Оборудование), время, вместимость и характеристики. Нажмите «Применить фильтры».

Бронирование (Календарь)
1. Из каталога выберите любой ресурс (например, кликните «Выбрать время»).
2. Откроется страница Календаря (calendar.html).
3. На сетке календаря кликните по свободной ячейке. Появится синий блок «Выбрано» на 1.5 часа.
4. Автоматически откроется модальное окно формы бронирования с подставленной датой и временем.
5. Нажмите «Подтвердить бронирование». Появится синяя плашка об успехе, а данные сохранятся в LocalStorage браузера.

Мои брони
1. Перейдите во вкладку «Мои брони».
2. Вы увидите карточку с только что созданной бронью (данные подтягиваются из LocalStorage).
3. С помощью вкладок можно переключаться между «Активными», «Историей» и «Отмененными» заявками.
4. Нажмите «Отменить бронь», чтобы удалить запись (данные в LocalStorage перезапишутся, и карточка исчезнет).


Особенности реализации
- Адаптивность: Проект корректно отображается на десктопах, планшетах и мобильных телефонах (используются @media запросы).
- UX/UI: Используются плавные анимации модальных окон и защита от отправки пустых форм (валидация).
- Хранение данных: Вся информация о бронированиях сохраняется в localStorage, что позволяет данным сохраняться при перезагрузке страницы.
